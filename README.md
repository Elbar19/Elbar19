# מעצב החדרים 🛋️

אפליקציית ווב (בעברית) שמעצבת חדר לפי סגנון, על בסיס מידות החדר ותמונה שלו.

## מה היא עושה
- **מידות → תוכנית העמדה**: מציבה רהיטים בקנה-מידה אמיתי (מבט על), עם התחשבות בדלת, בחלון ובמרווחי מעבר. פריטים שלא נכנסים מוחלפים בגרסה קומפקטית או מסומנים. אפשר לגרור פריטים בתוכנית.
- **תמונה → ניתוח**: מזהה את הצבעים הדומיננטיים, רמת התאורה וגוון החדר, ומציגה הדמיית "לפני/אחרי" בצבעי הסגנון.
- **7 סגנונות**: מודרני, סקנדינבי, תעשייתי, בוהו, מינימליסטי, קלאסי, ג׳פנדי — עם פלטת צבעים, חומרים, תאורה ודקור.
- **5 סוגי חדרים**: סלון, חדר שינה, חדר ילדים, חדר עבודה, פינת אוכל.
- **טווח מחיר חופשי** (מינימום–מקסימום בש"ח, עם טווחים מוכנים): רמת הגימור והמחירים מותאמים כדי להיכנס לטווח, ואם התקציב צפוף מוותרים על פריטים לא הכרחיים.
- **הדמיה תלת-ממדית** של החדר המעוצב, שנבנית מתוכנית ההעמדה ומתעדכנת כשמזיזים פריטים.
- **רשימת קניות** עם מחיר לכל פריט, כולל כמות צבע לקירות.
- **טיפים** מותאמים למידות ולתמונה, והדפסה / שמירה כ-PDF.
- **עם מפתח API של Anthropic (אופציונלי)**:
  - **נציגת AI ("נועה")**: שיחה שבה Claude שואל את כל השאלות הרלוונטיות (חדר, מידות, חלון, מי משתמש בחדר, סגנון, תקציב, תמונה) ואז מפיק את העיצוב בעצמו. אפשר לבקש ממנה שינויים והיא מעדכנת את העיצוב.
  - **ציור החדר**: Claude מצייר איור של החדר אחרי העיצוב, לפי התוכנית והתמונה.
  - **ניתוח תמונה**: Claude מסתכל על התמונה ונותן המלצות ספציפיות לחדר.

## הרצה מקומית
אין צורך בהתקנה. מכיוון שהקוד משתמש ב-ES modules צריך שרת סטטי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## הערה על מפתח ה-API
בניתוח ה-AI הקריאה ל-Claude יוצאת ישירות מהדפדפן, והמפתח נשמר רק ב-localStorage של הדפדפן.
זה מתאים לשימוש אישי. לאתר ציבורי צריך להעביר את הקריאה לשרת.

## מבנה
- `index.html`, `css/style.css` — ממשק
- `js/data.js` — סגנונות, סוגי חדרים, רהיטים ומחירים
- `js/layout.js` — אלגוריתם ההעמדה
- `js/photo.js` — ניתוח תמונה והדמיה
- `js/pricing.js` — התאמת מחירים לטווח התקציב
- `js/render3d.js` — הדמיה תלת-ממדית
- `js/ai.js` — קריאות ל-Claude (ניתוח תמונה, ציור החדר)
- `js/chat.js` — נציגת העיצוב (שיחה + כלי שמפיק את העיצוב)
- `js/app.js` — חיבור הכול ורינדור
